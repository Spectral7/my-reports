Executive Summary

HTML outperforms Markdown for complex AI work: it conveys tables, SVG diagrams, styling and interactivity, producing outputs people actually read and act on.

Key Points

Density. Tables, SVG, JS, CSS — beyond Markdown.
Clarity. People actually read polished docs.
Shareable. A link, not an attachment.
Interactive. Sliders, toggles, copy-to-prompt.
Context. Claude Code ingests repo + git for rich artifacts.
Commitment. Author dropped Markdown entirely.
